# Lil Sprouts Academy — Premium Practice Website

A polished, responsive static website concept designed to feel like a $1,000+ local-business website while remaining beginner-friendly.

## Files
- `index.html` — page structure and content
- `styles.css` — premium visual system, responsive layout, animations
- `script.js` — mobile menu, reveals, FAQ accordion, demo form
- `assets/lil-sprouts-logo.jpeg` — supplied logo

## Run locally
Open `index.html` in a browser, or use VS Code + Live Server.

## Before a real launch
Verify every business detail, program, hour, policy, address, phone number, email, and claim. Replace all text marked as placeholder/sample. Add real, approved photos and testimonials. The form is a demo and does not send submissions until connected to a real form backend.

## Easy editing map
- Text/content → `index.html`
- Colors/layout → `styles.css`
- Interactions → `script.js`
- Logo → `assets/lil-sprouts-logo.jpeg`

## Deployment
This static site can be deployed on GitHub Pages, Netlify, Vercel, or another static host. Connect a custom domain after deployment.

## Preview this copy
No installation or build command is required. Open `index.html`, or run:

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000. The files belong at the repository root, with the logo inside `assets/`.

## Publish with GitHub Pages
1. Open this repository's Settings → Pages.
2. Under Build and deployment, choose Deploy from a branch.
3. Select `main`, select `/ (root)`, and Save.
4. Wait for deployment to complete and use the Visit site link.

Expected address after enabling Pages: https://jasonmarshall111111-del.github.io/Practice-website-/

## Publish with Netlify
Import `jasonmarshall111111-del/Practice-website-` from GitHub. Use branch `main`, leave the build command empty, and publish directory `.`. The included `netlify.toml` sets that directory. Future commits to the connected branch update the site automatically.

## Preview versus business launch
This is a practice concept. The tour form validates fields locally but sends no email and saves no submissions. Confirm the contact information and hours, replace program/FAQ/schedule/photo placeholders, and connect and test a real form service before using it as the academy's live business site.
